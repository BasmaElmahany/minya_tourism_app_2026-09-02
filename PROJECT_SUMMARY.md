# Minya Tourism App - Project Summary

## 📋 Project Overview

This Flutter mobile application was created based on the tourism app requirements for Minya, Egypt. The app serves as a comprehensive digital tourism guide showcasing the rich cultural heritage and attractions of this historic Egyptian city.
